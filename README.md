# Student Study Planner

## Project Description
Student Study Planner is a simple web application that helps students organize and manage their study tasks and deadlines.

## Objective
- Organize study tasks
- Set due dates
- Mark completed tasks
- Delete tasks

## Technologies Used
- HTML
- CSS
- JavaScript
- GitHub
- GitHub Pages

## Features
- Add a study task
- Select a due date
- Mark a task as completed
- Delete a task

## How It Works
1. Enter a study task.
2. Select the due date.
3. Click "Add Task".
4. Click "Completed" when the task is finished.
5. Delete a task when it is no longer needed.

## Future Improvements
- Add reminders
- Add subject categories
- Store tasks permanently
- Add a progress tracker

## Project Output
